## 📚 Lessons Learned

### 1. Claude Code Worktrees Block Branch Deletion

**Problem**: `git branch -d claude/busy-pascal` failed with `cannot delete branch used by worktree`.
**Cause**: Claude Code creates git worktrees under `.claude/worktrees/<session-name>`.
**Fix**: Remove worktree dir, prune, then delete branch:

```powershell
Remove-Item -Recurse -Force ".claude/worktrees/<name>"
git worktree prune
git branch -d <branch-name>
```

### 2. GitHub Auto-Deletes Branches When PRs Are Closed

**Problem**: Steps 7 & 8 failed because remote refs no longer existed.
**Cause**: Closed PRs auto-delete source branches. Local tracking refs persist until pruned.
**Fix**: Run `git fetch --prune` first to sync local tracking refs with remote reality.

### 3. CI Automation Creates New Branches Mid-Cleanup

**Problem**: 2 new branches appeared (`license-update`, `sbom-update`) during cleanup.
**Fix**: Found, archived, and deleted them. A final sweep may always be needed.

### 4. OneDrive File Locks Interfere with Worktree Removal

**Problem**: `git worktree remove` failed with "Permission denied".
**Cause**: OneDrive sync locks files/directories.
**Fix**: Use `Remove-Item -Recurse -Force` followed by `git worktree prune`.
