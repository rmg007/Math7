# Secrets Locations & Management Map

> **SECURITY NOTICE:** This file lists *locations* of secrets. NEVER put actual secrets in this file.

## 📍 Where Secrets Live

| Scope | File Path | Status | Purpose |
|-------|-----------|--------|---------|
| **Project Root** | <code>[.secrets](/.secrets)</code> | **Active** | Primary source for API keys (Cloudflare, Supabase Service Key, Gemini). Not in Git. |
| **Admin Panel** | <code>[admin-panel/.env.local](/admin-panel/.env.local)</code> | **Active** | Frontend secrets (Anon Key). Generated by orchestrator. |
| **Student App** | <code>[student-app/.env](/student-app/.env)</code> | **Active** | Flutter environment config. |
| **Templates** | <code>[.secrets.template](/.secrets.template)</code> | **Public** | Safe template for new developers. Committed to Git. |

## 🛠️ Management Protocols

*   **Detailed Protocol:** <code>[docs/technical/SECRETS_MANAGEMENT.md](/docs/technical/SECRETS_MANAGEMENT.md)</code>
*   **Access Tool:** `scripts/deploy/sync-secrets.ps1` (Syncs root secrets to Cloudflare/Edge)

## 🚨 Incident Response
If a secret is leaked:
1.  **Rotate** the key immediately at the provider.
2.  **Update** the relevant file above.
3.  **Run** `npx supabase secrets set ...` for Edge Functions.
